Sigrun.

durable personal assistant

Your assistant should outlive the terminal you started it in.

Sigrun is a durable, multi-user personal-assistant server. One agent loop serves a web UI, a terminal UI, an HTTP API, and chat channels — over long-lived conversations stored in SQLite.

npm i -g @sigrun/sigrun && sigrun run

Node >=22.19.0

What that buys you

  • Durable

    Conversations, submissions, and schedules live in one SQLite database. Restart the process and the run resumes where it stopped.

  • One loop, many surfaces

    Web UI, terminal UI, HTTP API, and chat channels are all thin clients over the same durable conversations. The agent loop exists exactly once.

  • Replaceable parts

    Memory, integrations, tools, providers, and login are extensions — ordinary npm packages. Core does not privilege one implementation of any of them.

  • Multi-user, for real

    Real authentication plus a per-user execution jail. Sigrun fails closed when required isolation is unavailable rather than running everyone with full host access.

Ways to run it

  • npm

    One package, web UI included.

    npm i -g @sigrun/sigrun

  • Docker

    A compose reference in the repo.

    cd docker && docker compose up --build

  • Helm

    A PVC-backed Kubernetes deployment.

    helm install sigrun charts/sigrun
