Sigrun.

the assistant your household shares

One assistant. Everyone gets their own.

Sigrun is a self-hosted personal-assistant server built for more than one person. Each user signs in to their own conversations, settings, credentials, and tools, and their agent runs in its own sandbox. The core stays small: memory, model providers, and integrations are packages you pick.

npm i -g @sigrun/sigrun && sigrun run

Node >=22.19.0

What makes it different

  • Multi-user, for real

    Invites, API tokens, and OIDC, GitHub, or Discord sign-in. Each person's agent runs in a Landlock jail and can't read sigrun's files, its environment, or anyone else's. When the jail isn't available, a second user is refused — never quietly let in.

  • Small core, your parts

    Memory, model providers, tools, MCP servers, and login are ordinary npm packages you can swap. A broken one is quarantined, not a failed boot. A fresh install already ships codemode, MCP, tool search, sign-in, and a chat gateway built in.

  • Every surface, one conversation

    The web UI, terminal UI, HTTP API, and scheduled jobs are thin clients on the same conversations. Start in the browser, pick it up in the terminal mid-run. Chat-platform adapters plug into the built-in gateway.

  • Picks up where it stopped

    Conversations, runs, and schedules live in one SQLite database, on pi-durable. A restart resumes the run.

Ways to run it

  • npm

    One package, web UI included.

    npm i -g @sigrun/sigrun

  • Docker

    A compose reference in the repo.

    cd docker && docker compose up --build

  • Helm

    A PVC-backed Kubernetes deployment.

    helm install sigrun charts/sigrun
